# Primeiros Acordes 🎸

Site estático desenvolvido como trabalho da disciplina de Desenvolvimento Web I.

## Sobre o projeto

O projeto é uma página introdutória para pessoas que estão começando a aprender violão.

A página apresenta:

- primeiros passos para aprender violão;
- acordes iniciais;
- dicas de estudo;
- navegação entre as seções.

## Tecnologias utilizadas

- HTML5
- CSS3
- GitHub
- GitHub Pages

O projeto não utiliza JavaScript nem frameworks.
