## 1. Introdução
Este trabalho teve como objetivo aprender, na prática, como criar e publicar uma página web estática utilizando HTML, CSS, GitHub e GitHub Pages.
Para realizar o trabalho, desenvolvi uma página chamada **Primeiros Acordes**, com informações introdutórias para pessoas que estão começando a aprender violão.
O site foi desenvolvido utilizando HTML e CSS, conforme os requisitos da atividade. Não foram utilizados JavaScript ou frameworks.
## 2. Escolha do tema
O tema escolhido para o site foi o aprendizado de violão.
A página apresenta algumas informações básicas para iniciantes, incluindo primeiros passos, acordes iniciais e dicas de prática.
Escolhi esse tema porque considero música e violão assuntos interessantes e que permitem criar uma página simples, mas com diferentes seções e elementos visuais.
## 3. Ferramentas utilizadas
### HTML
Utilzei HTML5 para criar a estrutura da página.
O arquivo `index.html` contém os textos, títulos, seções, links e demais elementos que formam o conteúdo do site.
Também utilizei elementos semânticos como `header`, `nav`, `main`, `section`, `article` e `footer`.
### CSS
Utilizei CSS3 para definir a aparência da página.
O arquivo `style.css` é responsável pelas cores, fontes, espaçamentos, tamanhos, organização dos elementos e adaptação da página para telas menores.
Também utilizei Flexbox, Grid e media queries para organizar o layout e melhorar a visualização em diferentes tamanhos de tela.
### GitHub
Utilizei o GitHub para criar e armazenar o repositório público do projeto.
O projeto foi criado diretamente pelo navegador, sem utilizar o terminal.
### GitHub Pages
Utilizei o GitHub Pages para publicar o site na internet.
Depois da configuração, o GitHub passou a disponibilizar a página através de um endereço público.
## 4. Desenvolvimento do site
Primeiramente, criei um repositório público chamado `guia-violao` no GitHub.
Depois criei o arquivo `index.html` diretamente pelo navegador do GitHub e adicionei o código HTML da página.
Em seguida, criei o arquivo `style.css` e adicionei os estilos responsáveis pela aparência do site.
Também criei um arquivo `README.md` para explicar o objetivo do projeto e as tecnologias utilizadas.
Durante o desenvolvimento, organizei os arquivos da seguinte maneira:
```text
guia-violao/
├── index.html

└── RELATORIO.md
Durante o desenvolvimento utilizei os recursos de versionamento disponíveis no próprio GitHub.
